## 2. Related Vishnu.ai list — 10 GitHub repos to save ~90% tokens

From [vishnuai.in/github-token-savers](https://vishnuai.in/github-token-savers):

1. [rtk-ai/rtk](https://github.com/rtk-ai/rtk) — Rust Token Killer; filters terminal output before it hits context
2. [mksglu/context-mode](https://github.com/mksglu/context-mode) — sandboxes raw tool output into SQLite
3. [tirth8205/code-review-graph](https://github.com/tirth8205/code-review-graph) — local Tree-sitter knowledge graph of a codebase
4. [Mibayy/token-savior](https://github.com/Mibayy/token-savior) — MCP server that navigates code by symbols
5. [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) — terse "caveman" output style to cut tokens
6. [drona23/claude-token-efficient](https://github.com/drona23/claude-token-efficient) — CLAUDE.md that keeps responses short
7. [ooples/token-optimizer-mcp](https://github.com/ooples/token-optimizer-mcp) — MCP caching / compression / tool intelligence
8. [nadimtuhin/claude-token-optimizer](https://github.com/nadimtuhin/claude-token-optimizer) — reusable setup prompts for token optimization
9. [alexgreensh/token-optimizer](https://github.com/alexgreensh/token-optimizer) — finds silent context-eating tokens
10. [zilliztech/claude-context](https://github.com/zilliztech/claude-context) — code-search MCP so the repo is the context
